# shows-data

Listings and photos for the Small Revisions NYC Shows calendar.

- `shows.json` — listings, venues, neighborhoods, days, picks and photo credits (refreshed daily)
- `images/` — cropped artist photos (credits in `shows.json`)
- `index.html` — preview of the calendar

Served via GitHub Pages at https://smallrevisionsrss.github.io/shows-data/
